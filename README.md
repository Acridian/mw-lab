# Лаборатория Микроволн

Static Astro site for [mw-lab.ru](https://mw-lab.ru).

---

## Руководство для нетехнических пользователей

Этот раздел — для тех, кто не программист, но хочет вносить изменения на сайт. Вся работа происходит здесь, в репозитории на GitHub.

### Основные понятия

**Репозиторий** — место, где хранится весь сайт (тексты, изображения, код).

**Задача (Issue)** — ваш запрос на изменение. Например: «добавить новый товар», «исправить опечатку», «обновить контактный телефон».

**Пул-реквест (Pull Request, PR)** — набор готовых изменений для добавления на сайт. Когда задача выполнена, ассистент создаёт PR. Вы проверяете результат и подтверждаете публикацию.

**Ветка `main`** — основная версия сайта. Всё, что попадает в `main`, автоматически публикуется на [mw-lab.ru](https://mw-lab.ru).

### Как создать задачу

1. Перейдите на вкладку **Issues** в верхней части репозитория.
2. Нажмите зелёную кнопку **New Issue**.
3. Напишите заголовок: кратко, что нужно сделать. Например: _«Добавить усилитель MW-2000 на сайт»_.
4. В описании напишите все детали:
   - Что именно нужно изменить или добавить?
   - Есть ли готовый текст, фото, ссылки?
   - Где на сайте это должно появиться?
5. Нажмите **Submit new issue**.

### Как запустить ассистента

В комментарии к созданной задаче напишите **`/oc`**, а затем — описание на русском языке.

Примеры:

```
/oc Привет! Добавь на сайт новый товар. Название: Усилитель MW-2000. Описание: Мощный усилитель для лабораторий.
```

```
/oc Исправь опечатку на странице контактов: вместо «телефон» написано «телифон».
```

```
/oc Обнови номер телефона в шапке сайта на +7 (999) 123-45-67.
```

Ассистент изучит сайт, выполнит работу и создаст пул-реквест с изменениями.

### Что делать с пул-реквестом

Когда ассистент завершит работу, появится пул-реквест (PR). В комментариях к PR бот Netlify пришлёт ссылку **Deploy Preview** — это предпросмотр сайта с вашими изменениями. Нажмите на неё и проверьте результат.

Внизу страницы PR есть раздел **PR Checks**. Зелёная галочка ✅ означает, что сайт собран без ошибок.

#### Подтвердить и опубликовать

1. Откройте PR и просмотрите изменения.
2. Нажмите зелёную кнопку **Merge pull request**, затем **Confirm merge**.
3. Изменения попадут в `main`, и сайт обновится в течение 2–5 минут.

#### Запросить правки

Напишите в комментарии к PR:

```
/oc Внеси правки: <что исправить>
```

Ассистент обновит PR.

### Как проверить публикацию

После слияния PR изменения автоматически публикуются на [mw-lab.ru](https://mw-lab.ru). Чтобы отследить статус:

1. Перейдите на вкладку **Actions**.
2. Найдите запуск **Deploy to GitHub Pages** (самый верхний).
3. Зелёная ✅ — готово. Жёлтая 🟡 — ещё публикуется (обычно 2–5 минут). Красная ❌ — ошибка, напишите `/oc` в комментарии к задаче.

### Памятка

| Что делаю            | Куда                                              | Что писать                  |
| -------------------- | ------------------------------------------------- | --------------------------- |
| Хочу что-то изменить | Issues → New Issue                                | Заголовок и описание задачи |
| Запускаю ассистента  | Комментарий к задаче                              | `/oc <описание задачи>`     |
| Проверяю результат   | Pull Requests → открыть PR, ссылка Deploy Preview | —                           |
| Публикую             | Кнопка **Merge pull request**                     | —                           |
| Проверяю публикацию  | Actions → Deploy to GitHub Pages                  | —                           |
| Нужны правки         | Комментарий к PR                                  | `/oc <что поправить>`       |

Если что-то непонятно или пошло не так — создайте новую задачу (Issue) с описанием проблемы, и ассистент поможет.

## Для разработчиков

### Команды

```sh
npm install
npm run dev
npm run check
npm run verify
```

`npm run verify` type-checks, builds, checks all product outputs and legacy routes, validates publication redirects, search metadata, and the company PDF, and rejects old template strings and fake document links.

### Структура контента

- `src/content/products/` — карточки товаров (Markdown, экспорт из WordPress).
- `src/content/publications/` — публикации (Markdown, экспорт из WordPress).
- `src/lib/catalog.ts` — рубрикатор и порядок товаров.
- `src/lib/publications.ts` — внешние ссылки для чтения публикаций.
- `src/assets/images/products/` — изображения товаров.
- `src/assets/images/publications/` — обложки публикаций.
- `src/data/company.json` — контакты компании (телефон, email, адрес).
- `ASSET-CREDITS.md` — происхождение и условия использования изображений.

Не переписывайте импортированный Markdown в рамках визуальной работы. Вносите правки текста отдельными изменениями.
